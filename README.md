# Myna Quick Input — Расширение GNOME Shell

Расширение для GNOME Shell в Ubuntu, предназначенное для быстрого вызова окна ввода текста с поддержкой системного голосового ввода **Myna** (Ubuntu Speech-to-Text).

## Проблема и мотивация

В Ubuntu GNOME появляется новая технология распознавания речи **Myna** (`https://github.com/canonical/myna`). Однако при попытке использовать сторонние всплывающие расширения (например, Top Panel Note) для надиктовывания текста столкнулись с проблемами:
1. Окна существующих расширений не регистрируются как допустимые поля ввода (focusable input fields), куда Myna может направлять результат распознавания.
2. Горячие клавиши активации голосового ввода могут не срабатывать корректно поверх панелей расширений.

Данное расширение решает эту проблему, создавая специализированное модальное/всплывающее окно в GNOME Shell, имеющее полноценный фокус ввода и нативную поддержку текстовых полей, совместимых с системными средствами ввода и Myna.

## Основные возможности

- **Горячая клавиша:** Быстрый вызов окна ввода по настраиваемому сочетанию клавиш.
- **Совместимость с Myna:** Окно содержит стандартные элементы ввода текста (Clutter / Gtk / St entry), корректно принимающие фокус и сигнал от системных служб голосового ввода Myna.
- **Буфер обмена и экспорт:** Удобные кнопки для копирования надиктованного текста в буфер обмена, очистки и отправки в активное приложение.
- **Минималистичный интерфейс:** Легковесный виджет в верхке панели GNOME + всплывающее диалоговое окно ввода.

## Требования

- Ubuntu GNOME (GNOME Shell 45+)
- Установленная и настроенная служба Myna (`https://github.com/canonical/myna`)
