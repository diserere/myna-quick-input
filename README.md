# Myna Quick Input — Расширение GNOME Shell

Расширение для GNOME Shell в Ubuntu, предназначенное для быстрого вызова окна ввода текста с поддержкой системного голосового ввода **Myna** (Ubuntu Speech-to-Text).

## Проблема и мотивация

В Ubuntu GNOME (включая Ubuntu 26.04 с GNOME Shell 50) используется новая технология распознавания речи **Myna** (`https://github.com/canonical/myna`). Однако при попытке использовать сторонние всплывающие расширения (например, Top Panel Note) для надиктовывания текста столкнулись с проблемами:
1. Окна существующих расширений не регистрируются как допустимые поля ввода (focusable input fields), куда Myna может направлять результат распознавания.
2. Горячие клавиши активации голосового ввода могут не срабатывать корректно поверх панелей расширений.

Данное расширение решает эту проблему, создавая специализированное модальное/всплывающее окно в GNOME Shell, имеющее полноценный фокус ввода и нативную поддержку текстовых полей (`St.Entry`), совместимых с системными средствами ввода и Myna.

## Основные возможности

- **Быстрый вход:** клик по иконке микрофона в верхней панели — окно ввода открывается сразу, без промежуточного меню.
- **Совместимость с Myna:** Поле ввода (`St.Entry`) корректно принимает фокус и сигнал от системных служб голосового ввода Myna.
- **Буфер обмена и экспорт:** Кнопка «Копировать» переносит надиктованный текст в буфер обмена и закрывает окно; «Очистить» — стирает поле; «Закрыть»/`Esc`/клик по фону — закрывают окно.
