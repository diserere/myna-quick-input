# Архитектура расширения Myna Quick Input

## 1. Обзор архитектуры GNOME Shell Extension

Расширение разрабатывается в соответствии со стандартами GNOME Shell extensions (ESM / JavaScript, GObject, Clutter, St).

### Основные компоненты:
1. **`extension.js` (Точка входа):**
   - Управляет жизненным циклом расширения (`enable()`, `disable()`).
   - Регистрирует глобальные горячие клавиши (Keybindings) в Mutter / GNOME Shell.
   - Добавляет индикатор в верхнюю панель (Top Panel Indicator).

2. **`quickInputModal.js` (Окно ввода):**
   - Реализует модальное/всплывающее окно (`St.Bin`, `St.BoxLayout`, `St.Entry`).
   - Обеспечивает корректное управление фокусом ввода (`stage.set_key_focus()`), чтобы системные средства ввода и Myna распознавали поле как активное текстовое поле (`St.Entry`).
   - Предоставляет кнопки управления: "Копировать в буфер", "Очистить", "Закрыть".

3. **`metadata.json`:**
   - Метаданные расширения (UUID, совместимые версии GNOME Shell, имя, описание).

## 2. Интеграция с Myna и фокус ввода

Ключевое требование к окну — обеспечение совместимости с Myna. 
- Myna взаимодействует с фокусными полями ввода GNOME / GTK / Wayland через механизмы доступности (At-Spi) или стандартный фокус ввода Wayland/X11.
- Использование `St.Entry` внутри `St.Widget` с явным вызовом `stage.set_key_focus(entry)` гарантирует, что операционная система и служба ввода видят активное текстовое поле ввода.

## 3. План разработки

- **Этап 1:** Инициализация репозитория и базовой структуры расширения (`metadata.json`, `extension.js`).
- **Этап 2:** Реализация виджета в верхнеи панели и диалогового окна с полем ввода (`St.Entry`).
- **Этап 3:** Настройка глобальной горячей клавиши и управления фокусом.
- **Этап 4:** Добавление кнопок копирования/очистки и тестирование интеграции с Myna.
