# Инструкция по установке и тестированию

## 1. Установка расширения локально

Для тестирования расширения в вашей системе (например, в Ubuntu с GNOME Shell 50) необходимо скопировать или сделать симлинк папки проекта в директорию пользовательских расширений GNOME Shell.

### Шаг 1: Создание целевой директории
Директория для пользовательских расширений GNOME:
```bash
mkdir -p ~/.local/share/gnome-shell/extensions/
```

### Шаг 2: Создание символической ссылки на проект
Свяжите текущую папку проекта с папкой расширений под его UUID (`myna-quick-input@quick-draft.local`):
```bash
ln -s "$(pwd)" ~/.local/share/gnome-shell/extensions/myna-quick-input@quick-draft.local
```

---

## 2. Активация расширения

### Шаг 1: Перезапуск GNOME Shell
- **На сеансе X11:** Нажмите `Alt + F2`, введите `r` и нажмите `Enter`.
- **На сеансе Wayland:** Требуется выйти из системы (Log out) и войти снова (так как в Wayland перезапуск шелла «на лету» не поддерживается стандартным способом).

### Шаг 2: Включение расширения
Вы можете включить расширение через командную строку с помощью `gnome-extensions`:
```bash
gnome-extensions enable myna-quick-input@quick-draft.local
```

Или через графическое приложение **Утилита расширений (GNOME Extensions)** / GNOME Extensions App / Extension Manager.

---

## 3. Проверка работы с Myna

1. Нажмите на иконку микрофона в верхней панели GNOME или выберите пункт **«Открыть окно голосового ввода»**.
2. В появившемся темном модальном окне убедитесь, что фокус находится в поле ввода (`St.Entry`).
3. Активируйте голосовой ввод **Myna** (вашей горячей клавишей для Myna).
4. Проверьте, что распознанный текст успешно вводится в поле ввода, а кнопки «Копировать», «Очистить» и «Закрыть» работают корректно.
